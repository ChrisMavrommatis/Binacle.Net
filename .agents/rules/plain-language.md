# Write plainly

Plain, simple language in all docs, comments and explanations. Short is better - cut any word that does not
change the meaning.

Avoid jargon unless it is genuinely needed. When a plain word works, use it. Only reach for a technical term
when there is no simpler way to be exact, and then keep it.

Keep lines to about 120 characters. Break at a full stop when a line runs long.

This applies to every agent working in this repo, not just the main session.

**Why:** these files exist to be read fast by whoever picks the work up next.
