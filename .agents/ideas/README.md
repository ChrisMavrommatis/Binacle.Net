# Ideas

Rough, unvetted ideas. Not plans. No commitment, no timeline. Capture the thought and list the open
questions. Don't record who it came from or any personal/internal attribution — keep it about the idea.
When an idea gets picked up, move it to `.agents/plans/` and flesh it out.

Group ideas by slice, mirroring the repo — an idea that clearly extends one area lives in that slice folder
(e.g. `ideas/vipaq/`, `ideas/api/`); a net-new surface that maps to no existing slice stays at the root.

## Index

The manifest is generated — see [`_index.md`](_index.md). Regenerate it after adding or renaming an idea
with `config/agents-index.sh` (it also rebuilds the docs, plans, and memory indexes).
